# # Movie Library (Личная кинотека)

## Автор
Андреев Кирилл Евгеньевич

## Описание
Графическое приложение для ведения личной коллекции фильмов. Позволяет добавлять фильмы с указанием названия, жанра, года выпуска и рейтинга. Реализована фильтрация по жанру и году. Все данные сохраняются локально в файл `movies.json`.

## Требования
*   **Язык:** Python 3.x
*   **GUI:** Tkinter (стандартная библиотека)
*   **Хранение данных:** JSON (файл `movies.json`)

## Установка и запуск
1. Убедитесь, что у вас установлен Python 3.
2. Запустите приложение:
   ```
   python main.py
   ```
   (Внешние библиотеки не требуются).

## Использование
1.  **Добавление фильма:**
    Заполните все поля: *Название*, *Жанр*, *Год выпуска*, *Рейтинг*. Нажмите кнопку **«Добавить фильм»**.
2.  **Фильтрация:**
    Используйте поля *«Фильтр по жанру»* и *«Фильтр по году»* для поиска нужных фильмов в коллекции.
3.  **Сброс фильтра:**
    Нажмите кнопку **«Сбросить фильтр»**, чтобы снова увидеть полный список.
4.  **Сохранение:**
    Данные сохраняются автоматически при добавлении нового фильма и загружаются при запуске программы.

## Примеры использования (тесты)
1.  **Корректное добавление:** Введите «Начало», «Фантастика», «2010», «8.8». Фильм должен появиться в таблице.
2.  **Ошибка валидации (год):** Введите «Начало», «Фантастика», «Две тысячи десять», «8.8». Должно появиться окно с ошибкой про год.
3.  **Ошибка валидации (рейтинг):** Введите «Начало», «Фантастика», «2010», «одиннадцать». Должно появиться окно с ошибкой про рейтинг.
4.  **Фильтрация по жанру:** Добавьте несколько фильмов разных жанров. Введите «Комедия» в поле фильтра и нажмите «Фильтровать». В таблице должны остаться только комедии.
